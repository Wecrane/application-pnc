## 二、12 种 Metric 评分规则（8 赛题横向）

### 2.1 公共 Metric（8 赛题完全相同）

| Metric | 检测内容 | 配置 | 扣分 |
|--------|---------|------|------|
| **AccelerationLimit** | 加速度 ∈ [-6, +3] m/s² | single_deduction=1, unit=1 | 每超 1 扣 1/帧 |
| **CentripetalAccelerationLimit** | 向心加速度 ≤ 2 m/s² | 同上 | 每超 1 扣 1/帧 |
| **Collision** | 与障碍物距离 < 0.1m | distance=0.1, INCLUDE_BACK | 碰撞即致命 |
| **KeyPoint** | 按序经过检查点（radius=10m） | in_order, once_pass_stay_pass | 不计分（到齐即 100） |
| **OnRoad** | 必须在道路边界内 | use_road_boundary | 越界即致命 |
| **ReachEnd** | 进入终点区（5m×12m，部分重叠即可） | once_pass_stay_pass | 到达即 100 |
| **SpeedLimit** | 车速 ≤16.667 m/s + 区域限速 | **single_deduction=2, unit=1** | **每超 1m/s 扣 2/帧** |
| **TimeLimit** | 总时长 ≤ 90s | timeout=90 | 超时失败 |

### 2.2 场景专属 Metric（均 is_critical + require_all_time_pass + single_deduction=20）

| Metric | 出现 | 检测内容 | 配置 |
|--------|------|---------|------|
| DistToObstacleCar | scn2 | 与行人7673距离 ∈ [2, 5.5]m | min=2, max=5.5 |
| RedLightStop | scn3 | 红灯时距停止线 ∈ [1.5, 2.0]m | min=1.5, max=2.0 |
| RunStopSign | scn6 | 停牌前 1.5m 内完全停止 | distance=1.5 |
| CrosswalkStop | scn7 | 人行道前停住 ∈ [1.5, 2.0]m | min=1.5, max=2.0 |

### 2.3 扣分公式（已实测验证）

```
SpeedLimit 每帧 delta = ceil(超速量 / 1) × 2 = ceil(ego - limit) × 2
  例: 限速区 5.0, 车 16.7 → ceil(11.7)×2 = 24 分/帧（致命！）
      全局 16.667, 车 16.8 → ceil(0.13)×2 = 2 分/帧
停止类(RedLightStop/CrosswalkStop/RunStopSign): 每违规事件首帧扣 20
CrosswalkStop 冲过停止线: 每帧扣 100（硬失败）
```

**总分公式**：`总分 = max(0, 100 − Σ(100 − metric_score_i))`（扣分简单相加，非加权）

## 五、评分机制深度（sim_engine.log 解析要点）

1. **流程**：`Start running scenario` → `This is grading result`（text proto 块）→ JSON 汇总行 `{"status":1,"msg":{...}}` → `finish_pass/finish_fail`
2. **text proto 块**：`is_scenario_pass` / `score` / 每 metric 的 `metric_result{name, is_metric_pass, detailed_result{timestamp, is_pass, debug{description}, delta_score}, metric_score}`
3. **JSON 汇总**（推荐 json.loads）：`msg.metric_result[Name].{is_pass, metric_score, not_pass_timestamp, total_timestamp}`；`msg.score` 总分
4. **坑**：
   - Collision/DistToObstacleCar 的 `is_pass=false` = "无碰撞/无适用障碍"（安全帧，非扣分）
   - 只有**带 delta_score** 的帧才是真实扣分
   - `not_pass_timestamp` = [事件起, 事件止] 扁平对列表
5. **SpeedLimit 是 critical + require_all_time_pass**：任一帧违规 → is_metric_pass=false，但按累计扣分给部分分
