### 0.2 profile 覆盖机制（改配置的生效方式）
- **运行期实际读取**：`/apollo/modules/planning/...` = 工作区 `modules/planning/...`（源码目录）
- **覆盖层**：`profiles/default/modules/planning/`（当前只有 `planning_component/conf/planning.conf`）
- 改 `*.pb.txt` / `*.conf` 后：`aem profile use default` + 重启 Dreamview 即可生效，**无需编译**
- 改 C++ 源码 / 新增 proto 字段才需 `buildtool build -p modules/planning/ -j15`
- `profiles/current` 是指向 `profiles/default` 的软链接（当前默认 profile 即 default）

### 0.3 配置加载链路
```
PlanningComponent::Init()
  ├── planning.conf (gflags)            ← 全局参数（含 planning_upper_speed_limit 等）
  ├── planning_config.pb.txt            ← topic/pnc_map/learning_mode

        每个插件 Init() → __cxa_demangle → 自身 conf/*.pb.txt
```

## 九、结论与后续行动

1. **停车距离类（赛题 2/3/4）**：三个规则的 `stop_distance` 从 1.0 → 1.75，是纯配置改动，改 default profile 下的对应 `default_conf.pb.txt` 即可。
2. **赛题 5**：`stop_follow_distance=2.0` 刚好达标，实测后若 <2m 调大留裕量。
3. **赛题 6**：根据实测急加减速情况调 `follow_distance_scheduler` 的 slope 与 `follow_min_time_sec`。
4. **赛题 7/8（≤5m/s）**：现有配置**无法实现**——crosswalk/traffic_light 规则代码中无限速逻辑。选项：
   - a) 使用场景 `approach_cruise_speed`（仅左转有 2.78），不通用
   - b) 新增/启用限速机制（需改代码或加插件，违背"只改配置"）
   - c) 修改地图加限速（需地图工具，2026 地图当前只有 10/70km/h）
   - d) 检查 SpeedSetting 类 TrafficRule 是否可用（当前未注册）
5. **代码残留**：2 处 `mayaochang add` 定制（traffic_light 绿灯跳过、泊车碰撞检测），请确认是否保留。
