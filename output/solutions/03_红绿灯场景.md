# 赛题三：红绿灯场景 — 解题记录

> 状态：⏳ **配置已改，待实测验证（2026-08-01）**

---

## 1. 赛题要求

- 主车监测到前方红灯时，停车在停止线前 **1.5~2.0m**，不得超过停止线
- 评分：未停 1.5~2.0m 内扣 20 分

## 2. 场景信息

| 项 | 值 |
|----|-----|
| 场景名 | xh_2026_gsxx_红绿灯场景（全国总决赛仿真赛） |
| 地图 | Xh_2026_contest（mapId `69d51ffd0e41e1217f2fda19`） |
| 路线 | `Lane_1870 → Lane_1691 → Lane_710 → Lane_736 → Lane_731 → Lane_1960`（6 条，经四向路口） |
| 路线关键元素 | **Signal_5**（信号灯）、Crosswalk_11/12、Junction_9 |

## 3. 机制研究

```
TrafficLight TrafficRule（traffic_rules/traffic_light/）
  → 遍历参考线 signal_overlaps，红灯/黄灯构建虚拟停车障碍物
  → BuildStopDecision: stop_s = stop_line_s - config_.stop_distance()
  → 停车点 = 停止线前 stop_distance 米
```

**核心参数**：`traffic_light/conf/default_conf.pb.txt` → `stop_distance`

> ⚠️ 注意：源码中有一处 `// mayaochang add` 定制（绿灯/黑灯直接跳过，不建停车决策），影响绿灯放行逻辑。

## 4. 配置修改（default profile）

文件：`profiles/default/modules/planning/traffic_rules/traffic_light/conf/default_conf.pb.txt`（新建）

| 参数 | 原值（官方） | 新值 | 理由 |
|------|------|------|------|
| `stop_distance` | 1.0 | **1.75** | 1.0 不满足赛题 1.5~2.0m；1.75 为区间中间值留余量 |

其余参数（`enabled: true`、`max_stop_deceleration: 4.0`）保持官方值。

## 6. 经验复盘

1. 与赛题二（crosswalk）同模式：停车类规则都靠 `stop_distance` 控制，官方默认 1.0m 均不满足赛题 1.5~2.0m
2. 红灯放行逻辑受 `mayaochang add` 定制影响（绿灯/黑灯跳过），若绿灯异常需查 `traffic_light.cc:143`
