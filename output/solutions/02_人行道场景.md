# 赛题二：人行道场景（有人）— 解题记录

> 状态：⏳ **配置已改，待实测验证（2026-08-01）**（用户目测停车正常，但距离不达标）

---

## 1. 赛题要求

- 前方有人通过人行道时，停车在人行道前 **1.5~2.0m**，行人完全通过后继续行驶
- 评分：未停 1.5~2.0m 内扣 20 分；未避让/超线 0 分

## 2. 场景信息

| 项 | 值 |
|----|-----|
| 场景名 | xh_2026_gsxx_人行道场景 |
| 地图 | **xh_2025_contest**（mapId `67ee4d4c1abf4bf0a1d417ef`）⚠️ 注意不是 2026 地图 |
| 路线 | `Lane_1674`（起点终点同车道，经四向路口） |
| 路线关键元素 | **Crosswalk_62**（人行道）、Junction_14 |

## 3. 机制研究

```
Crosswalk TrafficRule（traffic_rules/crosswalk/）
  → 检测参考线 crosswalk_overlaps + 行人（expand_s_distance 外扩检测）
  → 有行人 → BuildStopDecision: stop_s = stop_line_s - config_.stop_distance()
  → stop_timeout 后行人未过完则放行
```

**核心参数**：`crosswalk/conf/default_conf.pb.txt` → `stop_distance`（停车距离）、`stop_timeout`（等待时间）

## 4. 配置修改（default profile）

文件：`profiles/default/modules/planning/traffic_rules/crosswalk/conf/default_conf.pb.txt`（新建）

| 参数 | 原值（官方） | 新值 | 理由 |
|------|------|------|------|
| `stop_distance` | 1.0 | **1.75** | 1.0 不满足赛题 1.5~2.0m（目测易误判，差距仅 0.5~1.0m） |

其余参数保持官方值：`max_stop_deceleration: 4.0`、`min_pass_s_distance: 1.0`、`expand_s_distance: 2.0`、`stop_strict_l_distance: 5.0`、`stop_loose_l_distance: 5.0`、`stop_timeout: 10.0`

提交：`b5d339e`

## 5. 生效与验证

```bash
aem profile use default
cat /apollo/modules/planning/traffic_rules/crosswalk/conf/default_conf.pb.txt  # 应显示 stop_distance: 1.75
aem bootstrap stop && aem bootstrap start --plus
```

验证：跑人行道场景（有人），停车后车头到人行道停止线距离应在 **1.5~2.0m**（勿仅目测）。

## 6. 经验复盘

1. **目测不可靠**：1.0 vs 1.5~2.0m 差距小，评分按精确距离检测
2. **地图要注意**：人行道场景在 xh_2025_contest（旧地图），不是 Xh_2026
3. 该 `stop_distance` 全局生效，同时影响赛题七（无人人行道，不停车，无副作用）
