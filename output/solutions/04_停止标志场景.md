## 7. 云端未到终点的根因：右转弯切内弯（0007 回放分析，2026-08-01）⭐

**用户观察**：云端评测回放中，车辆右转时**切内弯碰路肩** → 仿真停止 → 未到终点。本地未出现。

**本地 0007 回放数据**（本地到达终点 COMPLETE@5933）：
1. **右转弯段**（frame3900-4200，Lane_1353，半径 8.3m 急弯）：
   - 车辆实际轨迹相对 lane 中心**偏内峰值 0.95m**（带符号 +0.95，内弯侧）
   - 车宽 2.11m（半宽 1.055m）→ 车边缘距中心 2.0m，**与转弯车道边界间隙仅 ~0.3m**
2. **规划轨迹本身偏内**（`/apollo/planning` ADCTrajectory 对比 lane 中心）：
   - 转弯段（plan#400）规划点偏移 **0.93-0.94m**（全程稳定偏内）
   - 直行段（Lane_697）偏移 0.2-0.6m（正常）
   - → **是规划路径切内弯，不是车辆跟踪问题**（用户判断正确 ✅）

**根因（参考线平滑器）**：`discrete_points_smoother_config.pb.txt`
```
curb_shift: 0.2                        ← 参考线路缘内移
weight_fem_pos_deviation: 1e10         ← 几何平滑权重极大
weight_ref_deviation: 1.0              ← 参考跟随权重极小
```
FEM 平滑在急弯处**强烈切内弯**（几何平滑过冲）+ curb_shift 内移 → 参考线偏内 ~0.93m → LANE_FOLLOW_PATH 沿参考线生成路径也偏内。云端任何抖动（速度/误差）就碰内弯路肩。

**修复（profile 覆盖 smoother 配置，纯配置）**：
- `curb_shift` 0.2→0.0（取消路缘内移）
- `weight_fem_pos_deviation` 1e10→1e8（减弱平滑过冲）
- `weight_ref_deviation` 1.0→5.0（增强贴合车道中心）

**风险**：参考线平滑参数影响所有场景（更贴合车道中心通常更优）；需编译? 不需要——纯配置，`aem profile use default` + 重启 planning 生效。

**验证**：重录 0008（停止标志），检查转弯段规划轨迹偏移应 <0.3m。

## 3. 机制研究

**双机制**：
1. **StopSign TrafficRule**（`traffic_rules/stop_sign/`）：检测参考线 stop_sign_overlaps → `BuildStopDecision: stop_s = stop_line_s - config_.stop_distance()` → 停止线前 stop_distance 米
