## 7. 完整回放分析（202608011611 本地 16:09 录制）

### 7.1 场景机制确认

- **障碍物 7673 是行人（PEDESTRIAN）**（type=3，非车）
- 场景 JSON：行人初始静止 x=423446.67，**仿真 ≥50s 触发移动**（20m 内加速到 3m/s 走开）；终点 x=423491（行人后 44m）

### 7.3 云端抽搐根因（核心）

**机制**：行人移动时，感知同时给出：
- `obs7673`（**静止标记**）：speed_decider IsStatic 分支 → 建 **STOP**（1.75m 行人距离）
- `obs7673_0`（**动态子障碍**）：follow 76 / yield 7 交替

→ 静止 STOP + 动态 follow/yield **双重决策振荡** → 车"走一下停一下抽搐"。
本地时序恰好稳定；云端 perception/prediction 抖动放大振荡 → 超时未到终点。

**修复**（speed_decider.cc `mayaochang add2` 扩展）：
- 原 add2 只处理**移动 VEHICLE**（赛题四前车起步）
- 现扩展为 **moving_obstacle**（VEHICLE **或行人**）速度 >0.5 m/s 即不建静止 STOP，走 FOLLOW/YIELD
- 移动行人不建 STOP → 消除"静止 STOP + 动态 follow"振荡源
- 赛题二（人行道横穿）不受影响：横穿行人由 **crosswalk 规则 STOP(104)** 主导，speed_decider 静止 STOP 仅作兜底

### 7.4 二次评测仍抽搐 → 护栏 STOP 无条件过滤（2026-08-01）⭐

**用户反馈**：二次评测后车在**最后一段左侧护栏**处"闪烁 → 停止栅栏 → 抽搐前进"，动态跟随与障碍物停车避让两场景同病，导致关键点/终点/时间限制不过。

**护栏数据**（1611 回放）：护栏 = **UNKNOWN_UNMOVABLE(type=2)** 静态障碍物，多个离散点沿车道分布（x≈423298~423438, y≈4437613），全程速度 0。

**为什么原 add4 不够**：
- 原 add4 只在**横向 |l| > 1.355m（半宽1.055+0.3）** 时 ignore
- 最后一段弯道处**护栏出现在车正前方（|l|≈0）**→ 横向过滤失效 → 建 STOP
- 护栏感知**闪烁**（时有时无）→ STOP 栅栏反复出现/消失 → 车"走一下停一下"

**修复（add4 增强）**：
1. **UNKNOWN_UNMOVABLE（type=2）= 道路设施（护栏/路缘/建筑）→ 无条件 ignore 纵向决策**，不论横向位置——车沿参考线行驶不会撞道路设施，也无需为它停车
2. 横向过滤改为**障碍物中心横向偏移**（`(start_l+end_l)/2`），避免长条护栏跨越车道被 `min(|start_l|,|end_l|)` 误判为"横向很近"

**安全性复核**：
- 障碍物停车避让：障碍是 PEDESTRIAN(type=3) → 保留 STOP ✓
- 动态跟随：前车 VEHICLE(type=5) → 保留 STOP/FOLLOW ✓
- 8 个赛题无依赖 UNKNOWN_UNMOVABLE 纵向 STOP 的场景 ✓

## 3. 机制研究（关键）

### 3.1 静态障碍 → STOP 决策（停车距离天然达标）

```cpp
// speed_decider.cc:282-286  静态障碍
CreateStopDecision(*mutable_obstacle, &stop_decision,
                   -FLAGS_min_stop_distance_obstacle);   // stop_distance = -6.0
// CreateStopDecision:
//   fence_s = adc_sl_boundary_.end_s() + obstacle.min_s() + stop_distance
//   → 停车栅栏 = 障碍物前 FLAGS_min_stop_distance_obstacle = 6m
```

- `min_stop_distance_obstacle` gflag 默认 **6.0**（planning_gflags.cc:147）
- **停车距离 = 障碍前 6m，≥ 2m 赛题要求 ✅ 无需调整**
- `stop_follow_distance=2.0` 是 FOLLOW 决策（跟车）用的，**不是**静态障碍停车距离

### 3.2 绕行风险

- `obstacle_nudge_decider: enbale_nugde_static_obs=true`（静态障碍绕行评估）
- `obs_passable_buffer=0.7`：障碍两侧剩余空间 >0.7m 判定可绕 → 可能绕行不停车
- 若车绕行 → 未停车 → 可能扣 20 分 ⚠️

### 3.3 急减速风险

- DP `max_deceleration=-4.0`；若停车减速过猛 → 急减速扣分
- 需实测观察

## 6. 经验复盘

1. **静态障碍和跟车是不同机制**：静态障碍 STOP（6m），动态跟车 FOLLOW（stop_follow_distance）
2. `min_stop_distance_obstacle` gflag 是静态障碍停车距离，6m 天然满足 ≥2m
3. 赛题风险不在距离，而在**是否绕行**和**减速平顺性**
