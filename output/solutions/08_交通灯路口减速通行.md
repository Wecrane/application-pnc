## 1. 赛题要求

- 红灯变绿后主车继续行驶，通过交通信号灯区域时速度 **≤ 5 m/s**
- 评分：超速每 1m/s 每帧扣 2 分

## 3. 机制研究（关键：无现成限速机制）

与赛题七相同结论：纯配置无法实现，必须改代码。
- 红灯：traffic_light 规则建停车决策（1.75m，赛题 3 已配）
- 绿灯：现有代码 `// mayaochang add` 直接 `continue`（放行，无限速）→ 超速点

## 4. 代码修改

文件：`modules/planning/traffic_rules/traffic_light/traffic_light.cc`（绿灯分支）

```cpp
// mayaochang add
if (signal_color == perception::TrafficLight::GREEN ||
    signal_color == perception::TrafficLight::BLACK) {
  // 绿灯通过信号灯区域限速（≤5m/s，留裕量取4.5）
  reference_line_info->mutable_reference_line()->AddSpeedLimit(
      traffic_light_overlap.start_s, traffic_light_overlap.end_s, 4.5);
  continue;
}
```

限速值 4.5（赛题 ≤5，留 0.5 裕量）。

## 5. 副作用分析（安全）

| 影响 | 分析 |
|------|------|
| 赛题 3 红绿灯（红灯） | 红灯→停车决策，不受绿灯限速影响 ✅ |
| 其他绿灯路口 | 限速 5 通过，不扣分（只罚超速）✅ |
| 减速带/其他场景 | 无信号灯则不受影响 ✅ |

1. 与赛题七同方案（AddSpeedLimit 限速）
