# 赛题七：人行道路口减速通行（无人）— 解题记录

## 1. 赛题要求

- 主车通过**无人**的人行道时，速度 **≤ 5 m/s**
- 评分：超速每 1m/s 每帧扣 2 分

## 2. 场景信息

| ------------ | ----------------------------------- |
| 场景名       | xh_2026_gsxx_人行道路口减速通行     |
| 地图         | Xh_2026_contest                     |
| 路线         | `Lane_1674`（经四向路口）         |
| 路线关键元素 | **Crosswalk_62**、Junction_14 |

## 3. 机制研究（关键：无现成限速机制）

排查结论：

1. **地图限速无 5m/s**：2026 地图只有 10km/h（减速带）和 70km/h（默认）
2. **crosswalk 规则代码无限速逻辑**（grep SetSpeedLimit/AddSpeedLimit 确认）
3. **SpeedSetting 规则**存在但依赖外部 SpeedCommand（场景不发，不适用）
4. **场景 approach_cruise_speed** 只在裸路口/左转场景（protected 场景无此参数）
5. `ReferenceLineInfo` 只有全局 `LimitCruiseSpeed`，无按 s 区间 SetSpeedLimit

**结论：纯配置无法实现，必须改代码**（在 crosswalk 规则对无人人行道加 `AddSpeedLimit`，与减速带同款机制）。

## 4. 代码修改

文件：`modules/planning/traffic_rules/crosswalk/crosswalk.cc`（MakeDecisions 中）

```cpp
if (!pedestrians.empty()) {
  crosswalks_to_stop.emplace_back(crosswalk_overlap, pedestrians);
} else {
  // 无人人行道限速通过（≤5m/s，留裕量取4.5）
  reference_line_info->mutable_reference_line()->AddSpeedLimit(
      crosswalk_overlap->start_s, crosswalk_overlap->end_s, 4.5);
}
```

限速值 4.5（赛题 ≤5，留 0.5 裕量防控制超调）。

## 7. 经验复盘

1. **限速机制全貌**：Apollo 只有地图限速 + 减速带 gflag + SpeedSetting(外部指令) 三种，赛题限速需自建
2. `AddSpeedLimit(start_s, end_s, v)` 是通用限速 API（减速带同款），TrafficRule 中每帧调用即可
3. TrafficRule 在 Plan() 前执行（on_lane_planning.cc:374→382），限速区能被子 Task 读取
4. 限速值留裕量：赛题 ≤5 取 4.5
