## B. 代码改动（⚠️ 需要编译 `buildtool build -p modules/planning/ -j15`）

### B1. 赛题二：行人 STOP 距离独立化（commit `9777421`，分支 `feat/pedestrian-stop-distance`）

**背景**：静止行人被 speed_decider 当静态障碍用 6m（`min_stop_distance_obstacle`）建 STOP，覆盖 crosswalk 规则的 1.75m → 车停 6.9m 超标。需给行人单独距离。

**文件 1**：`modules/planning/planning_base/gflags/planning_gflags.cc`

```cpp
// min_stop_distance_obstacle 之后新增：
DEFINE_double(
        pedestrian_stop_distance,
        1.75,
        "stop distance from static pedestrian (meters); smaller than "
        "min_stop_distance_obstacle so crosswalk rule's stop wins");
```

**文件 2**：`modules/planning/planning_base/gflags/planning_gflags.h`

```cpp
DECLARE_double(pedestrian_stop_distance);   // 紧跟 min_stop_distance_obstacle
```

**文件 3**：`modules/planning/tasks/speed_decider/speed_decider.cc`
（`BELOW` → `obstacle->IsStatic()` 分支）

```cpp
} else if (obstacle->IsStatic()) {
    // stop for static obstacle
    // mayaochang add: for static pedestrian use a much closer stop
    // distance (pedestrian_stop_distance, default 1.75m) so that the
    // crosswalk rule's 1.5~2.0m stop is NOT overridden by the 6m
    // min_stop_distance_obstacle fence.
    double stop_dist = -FLAGS_min_stop_distance_obstacle;
    if (obstacle->Perception().type() == PerceptionObstacle::PEDESTRIAN) {
        stop_dist = -FLAGS_pedestrian_stop_distance;
    }
    ObjectDecisionType stop_decision;
    if (CreateStopDecision(*mutable_obstacle, &stop_decision, stop_dist)) {
        mutable_obstacle->AddLongitudinalDecision("dp_st_graph", stop_decision);
    }
}
```

**效果**：行人 STOP 栅栏与 crosswalk 一致（1.75m）→ 车停 1.5~2.0m 内。
**权衡**：`min_stop_distance_obstacle=6m` 不变，赛题五/六障碍物停车 ≥2m 不受影响。

### B2. 赛题七：人行道路口减速 ≤5m/s（commit `c31884e`）

文件：`modules/planning/traffic_rules/crosswalk/crosswalk.cc`（约 :176）

无人人行道分支（`else`）加限速：

reference_line_info->mutable_reference_line()->AddSpeedLimit(

reference_line_info->mutable_reference_line()->AddSpeedLimit(

### B4. 代码改动前置研究（为什么必须改代码，见各赛题文档）

- 9 个 TrafficRule 均**无限速逻辑**（crosswalk/traffic_light/stop_sign 无 SetSpeedLimit）→ 赛题七/八限速必须加代码
- `ignore_overlapped_obstacle` 是**死参数**（代码无 FLAGS_ 引用）
- speed_decider 的 `is_stop_for_pedestrain`（proto 默认 false）即使开启也用 6m → 行人距离必须代码区分

## C. prediction 修复（环境修复，非赛题，commit `eab08c0`）

**背景**：无 GPU 环境 torch 段错误，prediction 模块打不开。

- 8 个 torch 模型文件：删除 `if (torch::cuda::is_available())` CUDA 分支（16 处），强制 CPU
- `modules/prediction/conf/prediction.conf`：追加 `--nouse_cuda`
- 需编译：`buildtool build -p modules/prediction/ -j15`
- 另有方案A（已生效）：`~/.bashrc` 加 `export CUDA_VISIBLE_DEVICES=""`
