## 三、共性根因（限速机制失效的根本）

### 根因A：`GlobalSeenRedLight` 把 UNKNOWN 误判为"见过红"（traffic_light.cc）
```cpp
if (signal_color != GREEN && signal_color != BLACK) {
    GlobalSeenRedLight()[id] = true;  // ← UNKNOWN(未触发)也被置 true！
}
```
DISTANCE 触发的信号灯起步时未触发 = UNKNOWN → 永久"见过红" → 赛题8 限速全被跳过。
**修复**：只把 `RED/YELLOW` 记为见过红，UNKNOWN 不算。

### 根因B：QP 失败 fallback 丢限速（piecewise_jerk_speed_optimizer.cc）
`speed_optimize_fail_relax_velocity_constraint=true` 时，QP 不可行 → `set_dx_bounds(0, max(16.667, init_v))` → **限速被完全删除** → 车全速。
**修复**：fallback 保留限速（如 `set_dx_bounds(0, min(限速, init_v))`），或限速改软惩罚（高权重）。

### 根因C：限速区与终点/DEST 冲突导致 QP 不可行（赛题8）
限速区结束（227.7）到终点（229.75）仅 2m → QP 无解。
**修复**：限速区避免紧贴 DEST；或终点 STOP 进入限速区协调。

### 根因D：全局限速顶格零裕量（planning.conf）
`planning_upper_speed_limit=16.667` = 评测限速，控制超调 0.3-0.4 → 必超速。
**修复**：降到 16.0（留 0.6 裕量）。

### 根因E：限速区间窄（已部分修复）
原 `AddSpeedLimit(start_s, end_s)` 区间 0-4m（信号灯是点、斑马线窄）→ 高速无效。已修：提前 50m（0b98cb3）。

## 四、全局规划"不闪烁"研究

**现状**：滚动时域每帧重规划，限速/STOP 时有时无 → 速度锯齿（车 15→16.6→急停）。

**闪烁来源**（按影响）：
1. **QP fallback 二值化（主因）**：限速生效 ⇄ 不可行→放松→无限速，逐帧切换
2. traffic rule 逐帧开关（有无行人/信号灯颜色）；GlobalSeenRedLight 一旦置位=永久失效
3. 全局扫描远距人行道在窗口边缘进出
4. 参考线重建/换道时 s 跳变

**不闪烁方案**：
- **A（治本）**：fallback 保留限速（不丢）
- **B**：GlobalSeenRedLight UNKNOWN 不计入 + 3帧去抖
- **C**：参考线重建时按地图坐标重投影限速区
- **D**：限速区避免紧贴 DEST
- **E**：total_time=10（已做，长窗口一次规划）
