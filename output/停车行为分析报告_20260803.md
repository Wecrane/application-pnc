## 四、代码根因（机制专项实锤）

### 4.1 提前减速根因（piecewise_jerk_speed_optimizer.cc）
```
1. 限速预减速回推(:149-172): v_allow=√(lv²+2×4×(ls-path_s))
   → 同时压低【软 dx_ref(:173)】和【硬 s_dot_bounds(:180)】
   → 车在限速区前 ~32m 就被硬性要求 4m/s² 减速  ← 提前减速最直接链路
2. '一脚刹死'(:175-178): brake_dist=v²/(2×6)，但用 DP 参考时间轴触发
   → DP 参考偏慢时触发提前 → 提前刹
```

### 4.2 龟速蠕行正反馈（核心机制）
```
提前减速 → init_v 下降 → brake_dist=v²/(2×6) 缩水 → 刹死区后移
→ 下一帧更晚触发 → 持续提前缓刹 → 龟速滑行
叠加: 窗口10s + ref_v=70 强拉巡航 vs 硬 s≤stop_s → QP 保守解
```

### 4.3 终点速度跳变根因（按嫌疑排序）
| # | 根因 | 位置 |
|---|------|------|
| 1 | **QP fallback 二值化**（主）：终点前 QP 不可行 → relaxed→fallback 急停（首点 jerk=1000） | piecewise_jerk_speed_optimizer.cc:204-241, trajectory_fallback_task.cc |
| 2 | '一脚刹死' brake_dist 逐帧缩水 + dx_ref 阶跃 | :128-131, :175-178 |
| 3 | **DEST fence path_s 随参考线重建跳变**（st_stop_s 当帧重投影） | st_boundary_mapper.cc:172-189, destination.cc |
| 4 | FillEnoughSpeedPoints 尾巴（ds≤0 后填 v=0 到 3s） | speed_profile_generator.cc:24-43 |
| 5 | 轨迹拼接/控制过冲 | trajectory_stitcher.cc |

**scn8 实测终点问题**：参考线末端早于目的地 4m（destination.cc:77 警告×108）→ PATH_END fence 停住（非 DEST）→ 参考线重建时 fence 移动 0.41m → 车停后前冲 0.41m；终点减速段 QP/DP/fallback 失败 29 次 → 恰好 -4.00 急刹。

## 九、停车标志场景误伤诊断与修复（2026-08-03 用户反馈）

**用户反馈**：停车标志场景（scn6）"速度提不上去、好远就减速到很低"。

**日志 010015 实锤**：
- crosswalk 全局扫描在停车标志场景找到 **4 个斑马线**（Crosswalk_30/59/61/31），全部加 4.5 限速（提前 50m）→ 限速区 **s=131~197 连续覆盖 66m**
- 车从 s=131（**距停止标志 SS_StopSign_1 约 75m**）就降到 4.5 → 龟速爬行 ~11s
- 评测只查 RunStopSign（停止线前 1.5-2m 停），**斑马线不限速** → 纯误伤

**根因**：crosswalk 无人斑马线限速 4.5（为赛题7 scn8 的 Crosswalk_62 5m/s 设计）**过度泛化**——对所有无人斑马线生效，误伤有停止标志的场景。

**修复（71e62f0）**：crosswalk 限速分支增加判断——**斑马线 end_s 后方 30m 内有停止标志（stop_sign_overlaps）→ 跳过限速**（车本来就要停，限速冗余且有害）。停车标志场景 4 个斑马线全部跳过（距 SS 10-21m）；赛题7 Crosswalk_62 后方无停止标志 → 限速仍生效。

**遗留观察项**：停车标志场景终点段 v=-0.12 倒车 4s（DEST fence 参考线重建微调），不影响 ReachEnd/TimeLimit，P1-E 后待重编译观察。
