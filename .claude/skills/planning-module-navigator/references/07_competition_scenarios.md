# 星火自动驾驶大赛赛题说明

> 来源：`.claude/apollo-knowledge/赛题.md`

本文件列出 2026 百度 Apollo 星火自动驾驶大赛 PnC 赛道的全部赛题，包含场景描述和评分标准，供场景开发时参考。

---

## 赛题一：xh_2026_交通灯场景

**描述**：直行时，当主车监测到前方红灯信号时，主车需停车在停止线前 1.5 至 2.0 米处，不得超过停止线。在红灯状态下，车辆可右转通过。

**评分标准**：
- 主车停止距离未达到 1.5-2.0m 距离内，本场景扣 20 分

**对应插件**：
- `traffic_rules/traffic_light` — 交通灯规则
- `scenarios/traffic_light_protected` — 有保护交通灯路口
- `scenarios/traffic_light_unprotected_right_turn` — 无保护右转

---

## 赛题二：xh_2026_变道场景

**描述**：主车在当前车道行驶，前方遇障碍物或车道占用，需变更至相邻车道通行。变道前需观察目标车道后方来车，确认安全后完成变道。变道区域限速 30km/h。

**评分标准**：
- 未在规定时间内完成相关任务，本场景计 0 分
- 与障碍物或周围环境发生碰撞，该场景得 0 分
- 变道区域未限速，速度每超速 1m/s，每帧扣 2 分
- 连续变道（一次跨越多条车道），扣 40 分

**对应插件**：
- `tasks/lane_change_path` — 变道路径
- `traffic_rules/backside_vehicle` — 后方来车处理
- `traffic_rules/speed_setting` — 速度设置

---

## 赛题三：xh_2026_S弯场景

**描述**：主车向前行驶进入 S 弯区域，该路段为连续弯道，道路较为狭窄。主车需保持平滑轨迹通过 S 弯区域，限速 30km/h。如前方有障碍物，需安全评估后绕行通过，保持与障碍物的安全横向距离。

**评分标准**：
- 未在规定时间内完成相关任务，本场景计 0 分
- 与障碍物或周围环境发生碰撞，该场景得 0 分
- S 弯区域未限速，速度每超速 1m/s，每帧扣 2 分
- 绕行障碍物时横向距离不足，扣 20 分

**对应插件**：
- `scenarios/lane_follow` — 车道保持（处理弯道行驶）
- `tasks/lane_borrow_path_generic` — 借道绕行
- `scenarios/large_curvature` — 大曲率弯道（如有）

---

## 赛题四：xh_2026_U-Turn场景

**描述**：主车向前行驶进入路口准备掉头。需在掉头区域内完成 U 型转弯，掉头过程中需观察对向来车。掉头区域限速 30km/h。如掉头车道因障碍物或施工被占用，需绕开该区域完成掉头。

**评分标准**：
- 未在规定时间到达终点计 0 分
- 与障碍物或周围环境发生碰撞计 0 分
- U-Turn 区域未限速，速度每超速 1m/s，每帧扣 2 分
- 绕行障碍物时横向距离小于 1 米，扣 20 分
- 掉头过程中未避让对向来车，扣 20 分

**对应插件**：
- 可能涉及自由空间规划（U 型转弯）
- `tasks/lane_borrow_path_generic` — 借道绕行（绕施工区域）

---

## 赛题五：xh_2026_施工区域通行场景

**描述**：主车向前行驶，前方有锥桶表示道路施工，需要绕行，限速 30km/h，经过施工区域后取消限速。

**评分标准**：
- 驶入施工区域本场景计 0 分
- 通过施工区域但未限速，速度每超速 1m/s，每帧扣 2 分

**对应插件**：
- `tasks/lane_borrow_path_generic` — 借道绕行
- `scenarios/lane_follow` — 车道保持
- `traffic_rules/speed_setting` — 速度设置

---

## 赛题六：xh_2026_站点接驳场景

**描述**：主车向前行驶进入站点接驳区域，需精准停靠在指定接驳站点位置。应在站点泊车位处平稳停车，停车后保持静止等待 5 秒。等待完成后需观察周围环境确认安全后驶离站点。站点区域限速 30km/h。

**评分标准**：
- 未在规定时间内完成相关任务，本场景计 0 分
- 未停靠泊车位站点，本场景计 0 分
- 停车位置压线，扣 20 分
- 未等待规定时间提前驶离，扣 20 分
- 驶离站点时未观察周围环境或与障碍物发生碰撞，得 0 分
- 站点区域速度每超速 1m/s，每帧扣 2 分

**对应插件**：
- `scenarios/pull_over` — 靠边停车
- `scenarios/park_and_go` — 停车后起步
- `scenarios/valet_parking` — 泊车入库

---

## 赛题七：xh_2026_环岛场景

**描述**：主车向前行驶进入环岛区域，需在环岛入口处停车观察，让行环岛内正常行驶的车辆。确认安全后驶入环岛并根据目标出口选择正确车道通行。环岛内限速 30km/h。驶出环岛时需提前开启转向灯，观察后方来车后安全驶出。如环岛内有障碍物，需保持安全横向距离绕行通过。

**评分标准**：
- 未在规定时间到达终点计 0 分
- 与障碍物或周围环境发生碰撞计 0 分
- 环岛入口未停车让行环岛内车辆，本场景计 0 分
- 环岛内行驶未限速，速度每超速 1m/s，每帧扣 2 分
- 绕行障碍物时横向距离小于 1 米，扣 20 分
- 驶出环岛未开启转向灯，扣 20 分
- 选择错误出口，扣 20 分

**对应插件**：
- 环岛入口让行逻辑：可参考 `traffic_rules/yield_sign` 的让行机制
- `traffic_rules/backside_vehicle` — 后方来车处理
- `tasks/lane_change_path` — 变道路径（出口选择）

## 赛题开发要点总结

| 赛题 | 关键技术点 | 建议 priority |
|------|-----------|--------------|
| 交通灯 | 红灯停车 1.5-2.0m，右转可通行 | TrafficRule 开发 |
| 变道 | 安全变道判断，限速 30km/h，禁止连续变道 | Task（lane_change_path） |
| S 弯 | 平滑轨迹，狭窄弯道通行，限速 30km/h | 路径优化参数调优 |
| U-Turn | 掉头路径规划，对向来车避让 | 自由空间规划/新 Scenario |
| 施工区域 | 锥桶绕行，限速 30km/h，过后恢复 | Task（lane_borrow_path） |
| 站点接驳 | 精准停车，5 秒等待，安全驶离 | pull_over + park_and_go |
| 环岛 | 入口让行，环岛内行驶，出口选择，限速 30km/h | 新 Scenario/TrafficRule |
