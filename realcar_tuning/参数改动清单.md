## 二、逐文件详细改动（含注释，直接可上传）

### ① `planning_component/conf/planning.conf`（gflags）

```text
# ⚠️ 评分铁律 [1.5,5.1]：planning_upper_speed_limit 千万别动（越界整次判 0）
--planning_upper_speed_limit=5.0          # ✅ 保持（原 5.0）
# 原 5.0 → 2.8（评分 cruise ≤3.0556；3.0 实测速度峰值 3.14-3.16 会超速，2.8 留 0.25 裕量）
--default_cruise_speed=2.8                # ⭐ 修改
```

| 参数 | 原值 | 新值 | 修改依据 |
|------|------|------|---------|
| `--default_cruise_speed` | 5.0 | **2.8** | 评分 cruise 限速 ≤3.0556m/s；实车日志速度峰值 3.14-3.16（超 3.0556）→ 3.0 配置仍可能超调超速，取 2.8 留 0.25 裕量；同时降低停车接近速度（减速度更小，防 SKIP + 防加速度扣分） |
| `--planning_upper_speed_limit` | 5.0 | **5.0（不改）** | 评分铁律 [1.5,5.1]，越界整次判 0；已达标别动 |

> ⚠️ gflags 文件**不支持行尾注释**，RECOMMENDED 中已改为独立 `#` 注释行，上传安全。

### ② `traffic_rules/crosswalk/conf/default_conf.pb.txt`

```text
stop_distance: 1.25          # 原 0.10 → 1.25（评分停车 [1.0,1.5]m）
max_stop_deceleration: 4.0
min_pass_s_distance: 1.0
expand_s_distance: 6.0       # 原 0.0 → 6.0（提前识别行人防急刹）
stop_strict_l_distance: 4.0  # 原 1.0 → 4.0（官方默认；防 SKIP 提前放行：SKIP 条件需 l>此值）
stop_loose_l_distance: 5.0   # 原 1.5 → 5.0（官方默认；斑马线宽 3.9m，确保全宽行人必停）
start_watch_timer_distance:10
stop_timeout: 30.0         # 原 3.0 → 30.0（防行人未走完提前放行）
```

| 参数 | 原值 | 新值 | 修改依据 |
|------|------|------|---------|
| `stop_distance` | 0.10 | **1.25** | 评分停车 [1.0,1.5]m；0.1 停太近 → 扣 20 分 + 急刹 4.9-6.9 m/s² 双扣分（日志实证）；标定 1:1（仿真 1.75→1.78）取中值 |
| `expand_s_distance` | 0.0 | **6.0** | 行人提前进入检测区 → 车提前平缓减速，减速度 <3.0 不扣加速度分 |
| `stop_timeout` | 3.0 | **30.0** | 行人未走完不提前放行（评分 require_all_time_pass，提前走=硬失败风险） |
| `stop_strict_l_distance` | 1.0 | **4.0** | 🆕 回归 crosswalk.cc 源码：SKIP 条件 = `stop_deceleration≥4.0 且 l>stop_strict_l_distance` → 实车 1.0 时行人 l>1.0 就可能被放行（冲斑马线=评分硬失败 100）。调回官方默认 4.0：①扩大强停区 ②SKIP 需 l>4.0（行人几乎都在保护内） |
| `stop_loose_l_distance` | 1.5 | **5.0** | 🆕 回归源码：l≥loose 时仅路径交叉才停。实车 1.5 太小，行人横穿斑马线中段（l 1.5-3.9）可能落入弱保护。调回官方默认 5.0（≥斑马线宽 3.9m）确保全程必停 |
| `max_stop_deceleration` | 4.0 | 4.0（不改） | SKIP 阈值；靠巡航 2.8 + stop_distance 1.25 提前减速避免触发（不调大，调大允许急刹扣加速度分） |

## 四、审查中发现的风险点与预案

| # | 风险 | 证据 | 预案 |
|---|------|------|------|
| 1 | **gflags 行尾注释解析风险** | planning.conf 是 gflags 文件，行尾 `#` 可能解析失败 | ✅ 已改为独立注释行（RECOMMENDED 已修正） |
| 2 | **pb.txt 无末尾换行** | crosswalk/traffic_light/stop_sign 原文末行无 `\n` | 不影响 protobuf 解析（保留原样） |
| 3 | **`start_watch_timer_distance:10` 无空格** | 实车原样 | protobuf text 冒号后空格可选，合法；保留 |
| 4 | **减速带超速（进入区域未降速）** | 控制延迟 | limit 0.8→0.7 或 forward_buffer 8→10（现场微调） |
| 5 | **停车距离偏差（控制精度）** | 实车 LQR+PID vs 仿真 | 现场实测后 stop_distance ±0.1 微调（1.25→1.15 或 1.35） |
| 6 | **场景注入后感知状态** | 8/4 日志：Crosswalk_5 被感知为 UNKNOWN_UNMOVABLE（未注入时） | 现场确认注入后为真实信号灯/行人；若仍为静态障碍，红灯题可能改走障碍 STOP |
| 7 | **评分版本（新版 3 题 vs 旧版 4 题）** | 减速带限速 1.0 vs 1.5、有无 stop_sign | 现场确认；旧版才需 stop_sign 改动，减速带限速改 1.2 |
