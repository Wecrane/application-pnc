**两个"减速起点"是本次报告的核心**：

### ① 减速带/路口限速的减速起点 = 限速区段起点（插件计算）

`scene_speed_limit` 插件对目标元素（横道/信号灯）构建限速区段：
- **traffic_light 区段**（6am/6pm）：以**停止线 overlap** 为中心 → `[停止线Δy − forward_buffer 8, 停止线Δy + backward_buffer 8]`
- **crosswalk 区段**（7am/7pm）：以**横道 polygon** 为基准 → `[前缘Δy − forward 8, 后缘Δy + backward 5]`

**车头一进入区段起点，planning 立即把目标速度从 2.5 降到 0.7**（这就是"走到哪里开始减速"的精确位置）：

| 场次 | 限速目标元素 | 停止线/横道 Δy | **限速区段（减速起点→恢复点）** |
|------|------------|---------------|------------------------------|
| 6号上午 | Signal_1 常绿（停止线 overlap @24.71） | 24.71 | **[16.71 → 32.71]** |
| 6号下午 | Signal_6 常绿（停止线 overlap @26.84） | 26.84 | **[18.84 → 34.84]** |
| 7号上午 | Crosswalk_1（前缘 24.79 / 后缘 26.74） | 24.79 | **[16.79 → 31.74]** |
| 7号下午 | Crosswalk_1（前缘 24.79 / 后缘 26.74） | 24.79 | **[16.79 → 31.74]** |

> 减速带评分区（RoadSpeedLimit ≤1.0）：6am[24.73,30.53]、6pm[26.88,32.61]、7am[22.96,28.91]、7pm[23.5,29.1] —— **全部被限速区段完整覆盖**（forward=8 提前 8m、backward=8/5 覆盖尾段，整车盒判定也不越界）。

**减速过程**：2.5 → 0.7 需要约 1.8m/s 的降速，在 1.5m/s² 内约 1.2s、滑行约 1.9m → **在区段起点后约 2m 内完成降速，0.7 稳定通过整个区段**。

### ② 停车题的减速起点（行人/红灯触发）

- **人行道题**（6am / 7pm）：行人横穿时 crosswalk 规则（expand=6 提前检测）在**行人进入检测区即开始减速**，最终停在横道前 1.25m。
- **红灯题**（6pm / 7am）：traffic_light 规则在**车距信号灯 30m**（= 停止线前约 30m，即 Δy≈33）检测到红灯 → 开始减速 → 停停止线前 1.25m。

## 2.2 每个参数详解

### 参数 1：`default_cruise_speed`（planning.conf gflag）

- **原始值 5.0 → 新值 2.5**
- **作用**：全局默认巡航速度（无其它限制时的目标车速）。
- **为什么改**：评分巡航题要求**全程速度 ≤3.0556 m/s（11km/h）**。原始 5.0 远超上限必扣分（实车日志 road_speed 0 分的直接根因）。曾考虑 3.0，但实测 3.0 巡航速度峰值可达 3.14~3.16（加速爬坡过冲）→ 超速；**2.5 距上限 3.0556 留 0.5556 裕量**，且实车实测 2.5 巡航峰值仅 2.456（欠冲无超调），实际裕量 ≈0.6 更稳。
- **影响**：全场景速度基线。降低后所有减速/停车更平缓（加速度扣分风险更低），总时长略增（2.5 巡航 103m ≈41s，仍 <120s ✓）。

### 参数 2：`planning_upper_speed_limit`（planning.conf gflag）

- **原始值 5.0 → 新值 4.5**
- **作用**：planning 输出的**绝对速度上限**（速度规划硬约束）。
- **为什么改**：评分全局铁律 `cruise_speed_check`：该值必须 ∈[1.5, 5.1]，**越界整次判 0**。原始 5.0 距上限 5.1 仅 0.1，任何配置/四舍五入误差都可能越界 → **降 0.5 留安全垫**。4.5 远高于巡航目标 2.5，仅作加速天花板，对正常驾驶无行为影响。
- **影响**：全局安全网。改小不影响巡航（2.5<<4.5），只防止越界判 0。

### 参数 3：`min_stop_distance_obstacle`（planning.conf gflag）🆕 第八轮新增

- **原始值 0.0 → 新值 0.8**
- **作用**：speed_decider 所有 STOP 决策的**停车距离**（`CreateStopDecision` 用 `-FLAGS_min_stop_distance_obstacle`）→ 车停在**任意类型阻塞障碍物（含行人）前 N 米**（speed_decider.cc:204/255/283/293/332）。
- **为什么改（停车题命门）**：**实车横穿行人被感知为 `UNKNOWN` 类型**（192840 日志 28793/28780 实锤）→ crosswalk 规则类型检查（仅 PEDESTRIAN/BICYCLE）失败 → **crosswalk 从不建 STOP，expand 再大也无用** → 停车全靠 speed_decider 兜底。原始 0.0 = 停行人前 0m → 实测停车 0.26/0.32/0.36/0.62m 全部 <1.0 扣 20。**0.8 后停车 = 0.26~0.62+0.8 = 1.06~1.42m 全部 ∈[1.0,1.5] ✓**。
- ⚠️ **不能设 1.25**：0.26+1.25=1.51 超上限（若照搬 crosswalk stop_distance 会翻车）。
- **影响**：①人行道停车题（6am/7pm）**终极兜底** ②红灯题场景的行人/车辆同样受益 ③静态障碍物（锥桶）停 0.8m 前（更安全）④动态跟车 too_close 停 0.8m 前（更安全）⑤终点 DESTINATION 有独立决策，不受影响 ⑥限速题/加速度题无关。

### 参数 4：crosswalk `stop_distance`（traffic_rules/crosswalk/conf）

- **原始值 0.10 → 新值 1.25**
- **作用**：crosswalk 规则建 STOP 时，停车线相对横道前缘的距离。
- **为什么改**：停车题要求**车头距横道 [1.0,1.5]m**，越界扣 20。原始 0.10 → 停车 ≈0.26m（192840 实测）必扣分。**1.25 居中**，且仿真标定 1:1（stop_distance=1.75→实测 1.78，误差 0.03m）→ 1.25 直接落地。
- **影响**：人行道停车题（6am/7pm）——**规则触发时生效**；规则不触发时由参数 3 兜底（双保险）。

### 参数 5：crosswalk `expand_s_distance`（同上）

- **原始值 0.0 → 新值 6.0**
- **作用**：把横道检测区向四周扩展 6m → 行人提前进入 planning 视野，提前平缓减速。
- **为什么改**：原始 0.0 检测区=横道本身（8.7m² 很窄）→ 感知位置略偏即漏检。且实测 PEDESTRIAN 行人在横道旁 l=-3.5~-3.9（expand=0 的 polygon l=[-2.4,2.0] 不含）→ **expand=6 后 polygon l=[-8.4,8.0] 覆盖** → 这类行人若进入横道会触发 crosswalk 建 STOP。同时提供 6m 减速空间（2.5²/(2×6)=0.52m/s²，远低于加速度边界 −3）。
- **影响**：人行道停车题（6am/7pm）。⚠️ 对 **UNKNOWN 类型**行人无效（见参数 3）；对 PEDESTRIAN/BICYCLE 有效。

### 参数 6：crosswalk `stop_timeout`（同上）

- **原始值 3.0 → 新值 30.0**
- **作用**：crosswalk STOP 建立后，行人占用超过该时间 → 规则放弃 STOP（放行）。
- **为什么改**：行人横穿 8.2m，最慢 0.5m/s 需 16.4s；原始 3.0 超时后行人仍在横道 → 规则放行 → 车在行人未清空时移动 = **硬失败 100**。30.0 ≫ 16.4s（约 2 倍裕量），120s 限时内 70s 流程 + 30s 等待仍 <120s ✓。
- **影响**：人行道停车题（6am/7pm）放行安全性。

### 参数 7：crosswalk `stop_strict_l_distance`（同上）

- **原始值 1.0 → 新值 4.0**
- **作用**：crosswalk.cc 的 **SKIP（放行）条件阈值**：`stop_deceleration ≥4.0 且 行人横向距离 l > 此值` → 直接放行。
- **为什么改**：原始 1.0 → 行人横向 >1.0m 即满足 SKIP 放行 → 行人还在横道边缘时车冲过去 → 压横道/撞行人硬失败。**4.0 > 斑马线宽 3.9m** → 行人只要还在横道上就永不触发 SKIP → 必停。
- **影响**：人行道停车题（6am/7pm）防提前放行。

### 参数 8：crosswalk `stop_loose_l_distance`（同上）

- **原始值 1.5 → 新值 5.0**
- **作用**：行人横向分档阈值：l<strict 强停、strict≤l<loose 弱停（仅路径交叉才停）、l≥loose 放行。
- **为什么改**：原始 1.5 → 行人横穿中段（l=1.5~3.9m）落入弱停档 → 路径不交叉就放行 → 硬失败风险。**5.0 ≥ 横道宽 3.9m + 行人身体缓冲** → 横穿全程都在必停区。
- **影响**：人行道停车题（6am/7pm）。

### 参数 9：traffic_light `stop_distance`（traffic_rules/traffic_light/conf）

- **原始值 0.10 → 新值 1.25**
- **作用**：红灯时停车线相对停止线的距离。
- **为什么改**：红灯题要求**车头距停止线 [1.0,1.5]m**。原始 0.10 → 停车 0.1m（压线风险）必扣分。**1.25 居中**。
- **影响**：红灯停车题（6pm/7am）。⚠️ traffic_light 规则用**信号灯状态**（不依赖障碍物类型）→ 不受 UNKNOWN 问题影响，**1.25 可靠生效**。

### 参数 10~13：scene_speed_limit crosswalk 区段（限速插件）

- **`crosswalk_enabled` false→true**：**作用**：启用"人行道区域限速"区段。**为什么**：7am/7pm 的减速带评分区 = Crosswalk_1 位置 → 必须开人行道区段限速。**影响**：减速带题（7am/7pm）。
- **`crosswalk_forward_buffer` 1.0→8.0**：**作用**：横道前缘前 8m 开始限速（**7am/7pm 的限速减速起点 = 横道前缘 24.79 − 8 = Δy16.79**）。**为什么**：提前 8m 给 2.5→0.7 平缓减速空间；原始 1.0 会在评分区边缘才开始减速，加速度扣分 + 超速。**影响**：减速带题减速起点。
- **`crosswalk_backward_buffer` 1.0→5.0**：**作用**：横道后缘后 5m 结束限速（区段尾 26.74+5=31.74）。**为什么**：第五轮审查发现 2.0 时尾部有真实缺口 0.36~2.67m（整车盒判定车尾未出区即恢复加速 → 超速扣分），5.0 全覆盖评分区尾（7am 28.91 / 7pm 29.1 < 31.74 ✓）。**影响**：减速带题区段尾覆盖。
- **`crosswalk_limit_speed` 1.0→0.7**：**作用**：区段内目标速度。**为什么**：评分要求 ≤1.0，原始 1.0 无裕量（控制超调即超速）；0.7 留 0.3 裕量（实车实测 0.49，远安全）。**影响**：减速带题速度值。

### 参数 14~17：scene_speed_limit traffic_light 区段（限速插件）

- **`traffic_light_enabled` false→true**：**作用**：启用"信号灯区域限速"区段。**为什么**：6am/6pm 的减速带评分区 = Signal_1/Signal_6 位置 → 必须开信号灯区段限速。**影响**：减速带题（6am/6pm）。
- **`traffic_light_forward_buffer` 1.0→8.0**：**作用**：停止线前 8m 开始限速（**6am 减速起点 = 停止线 24.71−8 = Δy16.71；6pm = 26.84−8 = Δy18.84**）。**为什么**：同 crosswalk，提前平缓减速。**影响**：减速带题减速起点。
- **`traffic_light_backward_buffer` 1.0→8.0**：**作用**：停止线后 8m 结束限速（区段尾 24.71+8=32.71 / 26.84+8=34.84）。**为什么**：**signal overlap 在停止线位置**（比信号灯本体提前 1.1~1.35m）；第六轮审查发现 backward=5 时尾部缺口 0.79~0.81m（整车盒 1.66m → 9-10 帧超速 → 扣 20-40 分 + require_all_time_pass FAIL）→ **8.0 全覆盖**（评分区尾 30.53/32.61 < 32.71/34.84 ✓，裕量 1.4~2.2m）。**影响**：减速带题区段尾覆盖（**本次必须改的关键值**）。
- **`traffic_light_limit_speed` 1.0→0.7**：**作用**：区段内目标速度。**为什么**：同 crosswalk，留裕量。**影响**：减速带题速度值。

### 不改项（重要）

| 参数 | 值 | 为什么不改 |
|------|-----|-----------|
| `max_stop_deceleration` | 4.0 | SKIP 阈值。靠巡航 2.5 + 提前减速避免触发；调大=允许急刹扣加速度分 |
| `min_pass_s_distance` | 1.0 | 通行距离阈值，正常 |
| `max_stop_distance_obstacle` | 0.0 | 只影响 MinRadiusStopDistance（转弯），不影响 speed_decider 停车 |

| `follow_min_time_sec` / `stop_follow_distance` | 2.0 / 1.5 | 跟车参数，实车已合理，不涉及评分题 |
| control 全部参数 | — | 官方允许改 control，但实车 LQR+PID 已验证无超调（巡航 2.456 欠冲），不动（动了反而引入风险） |

期望值：`cruise=2.5`、`upper=4.5`、`min_stop=0.8`；crosswalk `stop=1.25/expand=6/timeout=30/strict=4/loose=5`；scene_speed_limit crosswalk+traffic_light 均 enabled、limit=0.7、forward=8、backward 5/8。

## 3.2 首圈必验证项（按优先级）

| # | 验证 | 期望 | 若不符 |
|---|------|------|--------|
| 1 | 减速带区速度（DreamView / 日志） | 区段内 ≤1.0（约 0.49~0.7） | 调 limit 0.6 或 forward 10 |
| 2 | **人行道停车距离** | 车头距横道 **1.0~1.5m**（期望 1.25 或兜底 1.06~1.42） | <1.0 → min_stop/crosswalk stop 调 0.9-1.0；>1.5 → 调 0.6-0.7 |
| 3 | 红灯触发识别（6pm/7am） | DreamView Signal_1 显示红/绿，车停停止线前 | 信号灯注入未识别 → 查感知 |
| 4 | 巡航峰值 | ≤3.0556（期望 ≤2.5 实测 2.456） | 若超 → cruise 降 2.2 |
| 5 | 放行时行人位置 | 行人已出横道 | 感知偏差 >1.6m 才可能触发，概率低 |
| 6 | 全程加速度 | ∈[−3,2] | 急刹出现 → 检查限速/停车减速起点 |

## 3.3 关键风险预案（详见参数改动清单风险表 #1~#9）

- **crosswalk 规则不触发**（感知 UNKNOWN）→ 已配 `min_stop_distance_obstacle=0.8` 兜底，停车仍达标
- **停车精度偏差**（控制误差 +0.16~+0.52m）→ 现场实测后 `stop_distance ±0.1` 微调
- **红灯注入识别失败** → 红灯题改走障碍 STOP 预案
