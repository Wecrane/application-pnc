# 本地评分复现器：验证报告（2026-08-06）

> **工具**：`scripts/local_grading_replay.py` —— 复用实车官方评分引擎（`grading_system_py`，纯 Python），输入实车 planning.log + 场景 json（行人重放）+ base_map.txt（横道几何）+ metric json，输出官方 5 项评分。
> **原理**：官方评分引擎核心（GradingEngine + 12 个 handler + feed_frame）本地可直接运行（36/38 单测通过）；地图用轻量解析替代 map_pb2（gitlink 占位符）；行人从场景 json agent 定义按"接近触发语义A"重放；截断到首次终点停稳（跳过测试倒车段）。

## 二、验证结论

1. **复现器精确复现官方扣分逻辑**：
   - ✅ 停车太近（0.284m）→ 扣 20；移动中 <1.0 → 硬失败 100
   - ✅ 减速带区超速（1.11）→ 检出（overspeed）
   - ✅ 减速带区达标（0.48/0.49）→ 100 分
   - ✅ 急刹 -4.0 → 扣 1 分
   - ✅ 高速贴行人 → Collision 硬失败
2. **实车原始配置（stop_distance=0.1）在 7pm 的评分**：192840=80 分（Crosswalk 停车太近扣 20）——与苏州 score_history "crosswalk 一半 0 一半 100" 规律吻合
3. **我们的推荐配置预期**（评分逻辑推导）：
   - stop_distance=1.25 → 停车 1.25 ∈ [1.0,1.5] ✓（消除 20 分）
   - 插件 0.7 → 减速带 <1.0 ✓（实测 0.49 已验证）
   - cruise 2.5 → <3.0556 ✓（实测 2.46 已验证）
   - expand 6 + 低速 → 无急刹 ✓（实测 2 帧）
   - **预期 100 分**（Collision 无、停车达标、巡航达标、限速达标、加速度达标）

## 三、使用方式

```bash
python3 scripts/local_grading_replay.py \
  --log <planning.log> \
  --scenario shiche/car_890/grading_console/auto_drive_console/7号下午_1.json \
  --map data/map_data/hehai_contest_7_pm_3/base_map.txt \
  --metric shiche/car_890/grading_console/auto_drive_console/metric \
  --field 7号下午
```

> 支持 6上午/6下午/7上午/7下午 四场次（`--field` 切换 + 对应地图/scenario）。
> 局限：①行人重放按"接近触发语义A"，若实车为语义B需调整 ②Collision 判定依赖行人重放精度，0.03m 级需结合真实感知核实 ③评分到"首次终点停稳"截断（跳过测试倒车）。
