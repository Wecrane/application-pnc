# 下载包无响应

### 问题描述:

下载包长时间无响应，一直卡在install xx...过程中 ![](https://apollo.baidu.com/docs/apollo/latest/docs/故障排查/安装编译/images/install_waiting.png)

### 问题原因:

软件包下载取决网络状态，有一些apollo软件包比较大，下载时间比较久
