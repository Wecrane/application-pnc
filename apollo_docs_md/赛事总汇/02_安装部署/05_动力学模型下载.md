**下载动力学模型为可选项，可根据队伍情况调整**

**前置条件，用户需要在容器内进行下面操作**

**删除原来的动力学模型** 

rm -rf ~/.apollo/resources/dynamic_models/models/
fragment

 **重新下载依赖** 

buildtool reinstall dreamview
fragment

 **关闭所有进程** 

bash kill_all.sh
fragment

 启动dreamview 

aem bootstrap start --plus
fragment
