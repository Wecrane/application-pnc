# 赛事编译缓存

> 
> ‍作者: 宇新 | 发布时间: 2023-06-02 17:04 | 链接: https://apollo.baidu.com/community/article/1075 
> 

## 前言：

针对电脑性能一般的情况，可能会出现编译时间过长、编译失败或因网络等问题无法正常编译的情况。为解决这个问题，百度Apollo星火自动驾驶大赛组委会提供以下解决方法：我们将提供预先编译好的编译缓存，以加快编译过程。

这项措施将帮助电脑性能较弱的参赛者更高效地完成编译任务，避免因编译时间过长或失败而影响比赛进度。同时，通过使用编译缓存，即使遇到网络等问题，参赛选手也可以顺利进行编译操作。

我们鼓励所有遇到编译困扰的参赛者使用这一功能，并确保您在比赛中有更好的体验。

## 使用前提：

> 
> ‍INFO 已经正确安装了Apollo 8.0（软件包方式）或者Apollo 8.0 pnc-competition版本； 
> 

## 获取方法：

赛事编译缓存：

提前编译好的planning模块缓存可以显著减少编译时间。

aem enter  # 该命令在宿主机执行，如果已在容器内，可以忽略这一步
cd /apollo_workspace/
wget https://apollo-pkg-beta.bj.bcebos.com/archive/planning_cache.tar.gz
sudo rm -rf .cache
tar -xzvf planning_cache.tar.gz
fragment

## 编译代码：

buildtool build -p modules/planning/
fragment
