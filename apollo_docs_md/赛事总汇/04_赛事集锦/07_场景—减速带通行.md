## 启动dreamview并观察默认代码下车辆通过减速带区域的仿真效果。

（1）在终端中，执行DreamView启动指令，执行成功后，打开浏览器输入（[http://localhost:8888/](http://localhost:8888/)）进入dremview中。

aem bootstrap start --plus
fragment

 ![](https://apollo.baidu.com/docs/apollo/latest/docs/赛事总汇/images/01_赛事竞赛/60bf1bba3e27e2e001ea023cd7d7e2ad.png)

当出现如下，即表示dreamview启动成功了。

![](https://apollo.baidu.com/docs/apollo/latest/docs/赛事总汇/images/01_赛事竞赛/53dd15bbad9f0e0ed40c92ab9f190fce.png)

（2）左侧导航栏打开Mode Setting面板，模式选择PnC Mode，操作选择Scenario_sim，进入仿真模式。

![](https://apollo.baidu.com/docs/apollo/latest/docs/赛事总汇/images/01_赛事竞赛/9d461fb9c3dc1dfe7f4e47aac29f5a8e.png)

### 减速带配置实践

在云实验终端界面点击在线编辑

![](https://apollo.baidu.com/docs/apollo/latest/docs/赛事总汇/images/01_赛事竞赛/b4dec6794fef50825633697519a36336.png)

打开相应文件路径：

profiles/default/modules/planning/planning_component/conf/planning.conf
fragment

 修改相关配置文件：

# 添加配置参数
--speed_bump_speed_limit=4.0
fragment

 ![](https://apollo.baidu.com/docs/apollo/latest/docs/赛事总汇/images/01_赛事竞赛/b41073b3616a82399f52ff5245f31411.png)

回到dreamview 查看仿真现象：

选择模式为：PnC，启动模块：planning、prediction，选择操作为：Scenario_Sim，

![](https://apollo.baidu.com/docs/apollo/latest/docs/赛事总汇/images/01_赛事竞赛/34056447a1f86b54cd17c7f6a3f1f361.png)

选择相应仿真场景后，点击左下角的开始按钮

![](https://apollo.baidu.com/docs/apollo/latest/docs/赛事总汇/images/01_赛事竞赛/ada87a2c4b681ccc45fb86582fa6e8ff.png)
