# 14_场景—特殊车辆绕行解题思路

# 特殊车辆绕行

> 
> ‍作者: 宇新 | 发布时间: 2023-06-22 13:36 | 链接: https://apollo.baidu.com/community/article/1088 
> 

# 解题方案：

## 方案一：

当自动驾驶车辆发现前方有特殊车辆且其速度低于10m/s时，需要进行换道操作。这时可以考虑修改换道决策，而不是选择借道决策，因为借道决策可能会影响慢速车的绕行决策。如果将前车视为静态障碍物，可能导致慢速车的绕行决策出现问题。
