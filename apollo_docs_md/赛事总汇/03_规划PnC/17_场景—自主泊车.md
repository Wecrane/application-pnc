# 17_场景—自主泊车

# 泊车场景

> 
> ‍作者: 宇新 | 发布时间: 2024-06-01 15:35 | 链接: https://apollo.baidu.com/community/article/1257

# 一、场景描述：

在主车进入停车场时，根据当前停车场的车位状况（有车位已被占用），搜索离自身最近的停车位。

## 场景图示：

![](https://apollo.baidu.com/docs/apollo/latest/docs/赛事总汇/images/04_规划PnC/07ded86a41d3faece9145e09cd8b4c1f.png)

# 二、实验流程

## 实验流程大纲

默认配置参数规划效果 启动dreamview并观察默认代码下车辆在泊车场景中的仿真效果。 泊车场景场景实践 添加planning scenario插件 修改相应代码 保存修改后的配置参数，并重新启动planning模块。 运行车辆规划模块，并在dreamview上观察车辆驶入泊车场景中的仿真效果。 

# 三、实验步骤

# 泊车场景场景实践

## 添加planning scenario插件

在包管理环境下创建插件模板，通过以下命令可以创建一个搜索停车位场景（BestParkingSpace）插件的模板 

buildtool create --template plugin   \
--namespaces planning   \
--dependencies planning:binary:planning   \
--base_class_name apollo::planning::Scenario   \
--class_name BestParkingSpace \
modules/planning/scenarios/best_parking_space
