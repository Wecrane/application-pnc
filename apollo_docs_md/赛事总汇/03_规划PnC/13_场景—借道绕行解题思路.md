# 借道绕行

## 场景描述：

```
车在单向车道行驶时，如遇前方车辆出现故障，主车可以借道绕行，为了保证行驶安全，借道区域应该在30米内。在借道时，主车必须仔细观察周围的车辆和行人，并确保安全地通过。

```

## 评判标准：

车在规定时间内或者30m范围内完成绕行，超出30m本场景计0分。

## 解题思路：

详见路径规划视频以及实验

## 0分分析：

绕行距离超过限制距离30m
