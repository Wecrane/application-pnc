# 测距

## 概述

测量两点之间的距离或多个点组成的折线长度总和，可以用于确定一段道路的长度、宽度、人行道长度等。

## 操作步骤

1. 单击 **测距** 按钮。
1. 在地图上单击一系列点。

测距工具可以显示两点之间的线段长度、；两点之间线段构成的夹角，以及各线段长度相加的总长度。最后一个点旁显示 X 按钮，可以清空此次绘制的坐标点序列。
